# Eski tek seferlik scriptler — ÇALIŞTIRMAYIN

Bu klasördeki dosyalar, landing/giriş sayfası tasarımı sırasında kaynak dosyaları toplu düzenlemek için
yazılmış tek seferlik yardımcı scriptlerdir. Proje kökünden buraya yalnızca arşiv amacıyla taşındılar.

- Çoğu, başka bir geliştiricinin makinesindeki mutlak yollara (`/Users/onur/Desktop/eduxofficial/...`)
  ve `apps/web/src/app/page.tsx` gibi kaynak dosyalara **doğrudan yazar**.
- Bugünkü kodla uyumlu değillerdir; çalıştırılırlarsa güncel kaynak dosyaların üzerine eski içerik yazabilirler.
- Uygulamanın çalışması için hiçbirine gerek yoktur.

İhtiyaç kalmadığı netleşince bu klasör tamamen silinebilir (dosyalar Git geçmişinde kalır).
